# 仕様

このドキュメントは[ドキュメント作成ガイドライン](/guides/documentation.md)・[要件・仕様書管理](/guides/requirements-specs-management/README.md)に準拠する必要があります。

_[トップに戻る](../index.md)_

各サービスリポジトリの OpenSpec で確定した仕様（archive したあとの `openspec/specs/`）を集める場所です。

- 置き場所は `docs/specs/<業務ドメイン>/<コンテキスト>/`（例: 注文コンテキストは `docs/specs/bookstore/ordering/`）
- 中身はサービスリポジトリからの同期で置き換わるので、**ここで直接編集しない**。直すときは、サービスリポジトリで change を作って archive し、同期し直す
- まだ同期された仕様はない
