# tasks.md 作成ガイドライン

このドキュメントは[ドキュメント作成ガイドライン](/guides/documentation.md)に準拠する必要があります。

_[要件・仕様書管理に戻る](./README.md)_

tasks.md は、実装の手順をチェックリストにするアーティファクトです。specs と design ができてから作ります。

## 守ること

- 1タスクは1つのはっきりした作業にする（目安は1コミット）
- 依存する順に並べる（モデル → API の定義 → 実装 → 検証）
- 検証のタスク（テスト・動作確認）を含める
- 最後に archive と、このリポジトリの `docs/specs/` への同期のタスクを置く
