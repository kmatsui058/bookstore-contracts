# design.md 作成ガイドライン

このドキュメントは[ドキュメント作成ガイドライン](/guides/documentation.md)に準拠する必要があります。

_[要件・仕様書管理に戻る](./README.md)_

design.md は、specs を満たすための設計（How）を書くアーティファクトです。

## 守ること

- 責務の分け方・境界・統合の箇所・処理の流れ・技術の選択とその理由を書く
- 振る舞いの契約（specs）と動機（proposal）を繰り返さない
- API の定義を変えるときは、このリポジトリの OpenAPI の定義とドメインモデルのどこを変えるかを書く
